# gogaghe — Architecture & Engineering Standards

> **One rule governs all others:** the core store engine must never import from the server or embedder layer. Data flows inward — server calls store, store knows nothing of gRPC or HTTP.

# Part 1 — Foundation

## 1. Unidirectional Package Dependency Graph

Dependencies flow **inward only**: `cmd → internal/server → internal/store ← internal/embedder`.

```text
Client (gRPC)
  ↓ calls RPC
internal/server/grpc.go       ← gRPC handler, metrics instrumentation
  ↓ calls Engine methods
internal/store/engine.go      ← thread-safe CRUD, TTL eviction, memory tracking
  ↓ snapshot for search
internal/store/bm25.go        ← BM25 inverted index (lexical)
internal/store/vector.go      ← cosine similarity worker pool (semantic)
internal/store/hybrid.go      ← Reciprocal Rank Fusion (RRF) merger
internal/store/eviction.go    ← cost-aware min-heap eviction
  ↑ callback on embed done
internal/embedder/client.go   ← async HTTP worker pool → sidecar
```

### Hard Rules

- **No upward imports:** `internal/store` MUST NEVER import from `internal/server` or `internal/embedder`.
- **No circular imports:** `internal/embedder` MUST NEVER import from `internal/server`.
- **`cmd/` is the only wiring layer:** dependency injection (engine, bm25, metrics, embedder) happens exclusively in `cmd/gogaghe-server/main.go`.
- **`pkg/` is generated code:** files under `pkg/gogaghe/v1/` are auto-generated by `buf generate`. Never edit them manually.
- **Zero Cgo:** `CGO_ENABLED=0` everywhere — in `Makefile`, `Dockerfile`, and CI. The binary must cross-compile to any Linux/amd64 target without a C toolchain.

# Part 2 — Data & Concurrency Rules

## 4. The `Item` Type — Source of Truth

```go
type Item struct {
    Value          []byte
    CostMs         int64     // computation cost for eviction scoring
    Vector         []float32 // optional — populated async by embedder
    AccessCount    int64     // incremented on every Get()
    LastAccessedAt time.Time
    ExpiresAt      time.Time // zero = no expiry
}
```

- `Vector` is the only field allowed to be updated post-Set (by the embedder callback).
- Never mutate an `Item` outside of `Engine.Set()`.

## 5. Thread Safety Contract

| Operation | Locking | Notes |
| :--- | :--- | :--- |
| `Engine.Set()` | `sync.Mutex` (write) | Updates map + atomic memory counter |
| `Engine.Get()` | `sync.Mutex` (write) | Updates `AccessCount` + `LastAccessedAt` |
| `Engine.Delete()` | `sync.Mutex` (write) | Decrements atomic memory counter |
| `Engine.Len()` | `sync.RWMutex` (read) | Read-only |
| `Engine.Items()` | `sync.RWMutex` (read) | Returns full defensive copy |
| `Engine.MemoryUsageBytes()` | `sync/atomic` | Lock-free read |

- `Engine.Items()` returns a **snapshot copy** — search operations iterate the snapshot, never holding the engine lock during long computations.

## 6. Memory Accounting

- `itemSize(key, item)` estimates: `len(key) + len(value) + len(vector)*4 + unsafe.Sizeof(Item{})`.
- `Engine.Set()` checks limit **before** acquiring the write lock. Returns error immediately on overflow.

# Part 3 — Search & Eviction

## 7. BM25 Index Lifecycle

- `BM25Index.Rebuild(items)` is called after every `Set` and `Delete` in the gRPC handler.
- Full index reconstruction (not incremental). Acceptable for in-memory portfolio scale.
- Constants: `k1 = 1.5`, `b = 0.75`.

## 8. Vector Search Worker Pool

- `VectorSearch(queryVec, items, topK)` spawns `runtime.GOMAXPROCS(0)` workers.
- Items with `len(Vector) != len(queryVec)` are silently skipped.
- Cosine similarity of zero vectors returns `0.0` (no panic).

## 9. Reciprocal Rank Fusion

```
RRF score(key) = Σ  1 / (k + rank_i(key))
```

- Default `k = 60.0`. Ranks are 1-based.

## 10. Cost-Aware Eviction Priority

```
priority(item) = CostMs / (AccessCount + 1)
```

- Lower priority = evict first (cheap + unused go first).
- `Evict(engine, targetBytes)` loops, calling `heap.Pop()` + `engine.Delete()` until under target.

# Part 4 — gRPC & API Standards

## 11. RPC Contract

| RPC | Notes |
| :--- | :--- |
| `Set` | Triggers async embed if `auto_embed=true` and embedder is enabled |
| `Get` | Returns `found=false` on miss or expired key |
| `Delete` | Returns `deleted=false` for non-existent key |
| `VectorSearch` | Skips items with no vector or dimension mismatch |
| `HybridSearch` | Uses both `query` text (BM25) and `query_vector` (cosine) merged via RRF |

```bash
make proto   # runs: buf lint && buf generate
```

Never edit files under `pkg/gogaghe/v1/` manually.

## 12. gRPC Status Codes

| Condition | Status |
| :--- | :--- |
| Memory limit exceeded on `Set` | `codes.ResourceExhausted` |
| Key not found | `codes.OK` with `found=false` |
| Internal bug | `codes.Internal` |

## 13. Server Reflection

Always enabled via `reflection.Register(grpcSrv)`. Required for Postman, Kreya, grpcurl introspection.

# Part 6 — Async Embedder

## 16. Embedder Lifecycle

- Created only when `embedder.enabled: true` in config.
- `Client.Enqueue(req)` is **non-blocking** — drops with `slog.Warn` if buffer full.
- Callback is called from worker goroutines — must be goroutine-safe.
- `Client.Stop()` closes the job channel and waits for drain via `sync.WaitGroup`.

## 17. Sidecar HTTP Contract

```
POST /embed
Content-Type: application/json

Request:  { "text": "string to embed" }
Response: { "vector": [0.1, 0.2, ..., 0.N] }
```

# Part 8 — Testing Standards

## 19. Test Strategy

| Level | Tool | Scope |
| :--- | :--- | :--- |
| Unit + Race | `go test -v -race ./...` | Engine CRUD, TTL, BM25, vector, RRF, eviction |
| Build | `make build` | Full binary, `CGO_ENABLED=0` |
| Docker | `docker compose config` | Compose file syntax |

### Mandatory Test Helper Pattern

```go
func newTestEngine(t *testing.T) *store.Engine {
    t.Helper()
    e := store.NewEngine(64*1024*1024, 100*time.Millisecond)
    t.Cleanup(e.Stop)  // stops TTL goroutine — prevents goroutine leak
    return e
}
```

`t.Cleanup(e.Stop)` is **mandatory** on every engine created in tests.

## 20. Race Detector is Non-Negotiable

Any failure under `go test -race` is a **critical bug**, not a warning. The `-race` flag must appear in `make test` and CI.

# Part 9 — The Golden Do's & Don'ts

### ✅ DO'S

- Always run `make proto` after any change to `api/proto/gogaghe/v1/gogaghe.proto`.
- Always call `t.Cleanup(e.Stop)` for every `Engine` created in tests.
- Always use `Engine.Items()` (snapshot copy) for search — never iterate the internal map directly.
- Always pass `CGO_ENABLED=0` when building.
- Always update Prometheus gauges after every `Set` and `Delete`.
- Always call `bm25.Rebuild(engine.Items())` after any write that changes item text.

### ❌ DON'TS

- NEVER import `internal/server` or `internal/embedder` from `internal/store`.
- NEVER edit files under `pkg/gogaghe/v1/` — auto-generated.
- NEVER use `CGO_ENABLED=1` — breaks scratch image cross-compilation.
- NEVER call `engine.Get()` or `engine.Set()` while holding an external lock — deadlock risk.
- NEVER make blocking network calls in a gRPC handler — use `embedder.Enqueue()`.
- NEVER register metrics on `prometheus.DefaultRegisterer` — use the isolated registry.
- NEVER skip `-race` in tests — concurrent bugs are invisible without it.
